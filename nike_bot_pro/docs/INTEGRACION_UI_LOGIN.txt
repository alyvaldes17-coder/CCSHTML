🧩 CÓDIGO PARA INTEGRAR EN LA UI
-----------------------------------

En el archivo que maneja cada cuenta (probablemente ui/app.py):

1️⃣ IMPORTAR LAS FUNCIONES

    from auth.session_check import check_session_nike, login_from_ui


2️⃣ ESTADO NUEVO DE CUENTA

Agregar a los estados:

    LOGIN_REQUIRED = "LOGIN_REQUIRED"


3️⃣ VERIFICAR SESIÓN AL CARGAR CADA CUENTA

    def update_account_state(account):
        account.is_logged_in = check_session_nike(account.account_path)
        
        if account.is_logged_in:
            account.state = "READY"
        else:
            account.state = "LOGIN_REQUIRED"


4️⃣ BOTÓN LOGIN (visible solo si LOGIN_REQUIRED)

    def show_login_button(account):
        if account.state == "LOGIN_REQUIRED":
            # Mostrar botón
            button = tk.Button(
                text="Login Nike",
                command=lambda: on_login_clicked(account)
            )
            button.pack()


5️⃣ HANDLER DEL BOTÓN LOGIN

    def on_login_clicked(account):
        print("[UI] Abriendo login para {}".format(account.name))
        
        login_from_ui(account.account_path, account.name)
        
        # Después de que cierre Chrome, verificar de nuevo
        update_account_state(account)
        
        print("[UI] Sesión verificada nuevamente")


6️⃣ BLOQUEAR PLAY SI NO HAY LOGIN

    def on_play_clicked(account):
        if account.state == "LOGIN_REQUIRED":
            show_error("Requiere LOGIN antes de PLAY")
            return
        
        # ... código de PLAY normal
