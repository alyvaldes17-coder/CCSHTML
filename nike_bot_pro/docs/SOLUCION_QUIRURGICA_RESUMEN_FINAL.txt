TECNOLOGIA: WMIC (Windows Management Instrumentation Command-line)
================================================================================

COMANDO EJECUTADO:
    wmic process where "name='chrome.exe' and CommandLine like '%AUTH%CUENTA2%PROFILE_PW%'" call terminate

DESGLOSE:
  wmic process where = "dame procesos WHERE"
  name='chrome.exe' = el proceso se llama chrome.exe
  and = AND lógico
  CommandLine like '%...%' = la línea de comando CONTIENE (% = comodín)
  auth/cuenta2/profile_pw = carpeta específica (en los %)
  call terminate = termina el proceso

POR QUE FUNCIONA:
  1. Windows mantiene línea de comando de cada proceso
  2. WMIC puede buscar por patrón de texto
  3. Si un Chrome abre con --user-data-dir=auth/cuenta2/profile_pw,
     su línea de comando CONTIENE esa ruta
  4. Tu Chrome personal NO tiene esa ruta en su línea de comando
  5. WMIC solo mata el que cumple el patrón
  6. Tu Chrome NO cumple → NO MUERE

SI ALGO FALLA
================================================================================

PROBLEM: Chrome no abre
FIX:
  1. Abre Task Manager (Ctrl+Shift+Esc)
  2. Busca chrome.exe
  3. Verifica si hay procesos huérfanos
  4. Si hay, mátalos manualmente
  5. Intenta nuevamente

PROBLEM: WMIC no responde
FIX:
  1. El archivo ya tiene try/except
  2. Si WMIC falla, Chrome intentará abrir IGUAL
  3. Si sigue sin abrir, reinicia Windows
  4. (WMIC debería estar en Windows 10+)

PROBLEM: Carpeta sigue bloqueada
FIX:
  1. Reinicia Windows (libera todos los procesos)
  2. Intenta nuevamente
