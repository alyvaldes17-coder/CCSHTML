PROBLEMA 1: "Chrome no abre"
─────────────────────────────────────────────────────────────────────────────
Síntomas:
  • force_login.py ejecuta sin errores
  • Pero Chrome no aparece en la pantalla

Causas:
  1. Chrome no instalado en rutas estándar
  2. Antivirus/firewall bloqueando
  3. Permisos de usuario insuficientes

Soluciones:
  1. Instala Chrome desde google.com/chrome
  2. Ejecuta como Administrador:
     • PowerShell > Click derecho > "Ejecutar como administrador"
     • python force_login.py
  3. Temporalmente desactiva antivirus y reintentra


PROBLEMA 2: "Chrome abre pero está vacío/blanco"
─────────────────────────────────────────────────────────────────────────────
Síntomas:
  • Chrome se abre pero muestra página en blanco o vacía

Causas:
  • Ruta de perfil problemática
  • Permisos de escritura en disco

Soluciones:
  1. Mata Chrome: taskkill /F /IM chrome.exe
  2. Elimina la carpeta del perfil:
     rmdir /S /Q auth\cuenta2\profile_pw
  3. Corre force_login.py nuevamente


PROBLEMA 3: "Chrome abre pero dice 'Sync error' o cosas rojas"
─────────────────────────────────────────────────────────────────────────────
Síntomas:
  • Chrome abre pero con errores de sincronización

Soluciones:
  1. Ignora los errores (son normales en perfil nuevo)
  2. Loguéate normalmente
  3. Cierra Chrome
  4. Listo
