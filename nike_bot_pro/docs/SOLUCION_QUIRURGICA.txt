COMANDO WMIC (EXPLICADO):
━━━━━━━━━━━━━━━━━━━━━━━

wmic process where "name='chrome.exe' and CommandLine like '%AUTH%CUENTA2%PROFILE_PW%'" call terminate

Desglose:
  wmic = Windows Management Instrumentation Command-line
  process where = "dame procesos DONDE se cumplan estas condiciones"
  name='chrome.exe' = el proceso se llama chrome.exe
  and = AND lógico
  CommandLine like '%...%' = la línea de comando CONTIENE (like = like SQL)
  %AUTH%CUENTA2%PROFILE_PW% = nuestra ruta específica (los % son comodines)
  call terminate = termina el proceso

Ejemplo real:
  Si hay: C:\Users\beriann\...\nike_bot_pro\auth\cuenta2\profile_pw\chrome.exe ...
  WMIC dice: "¡Ese cumple! Termina."
  
  Si hay: C:\Program Files\Google\Chrome\... (tu Chrome normal)
  WMIC dice: "Ese NO usa auth\cuenta2. Lo dejo vivo."


POR QUÉ FUNCIONA:
━━━━━━━━━━━━━━━━━

1. Windows bloquea carpetas cuando procesos las tienen "abiertas"
   └─ Si profile_pw está bloqueada, no se puede abrir de nuevo

2. El bot puede dejar procesos "fantasma" (que siguen vivos pero invisibles)
   └─ Logs dicen "Chrome abierto" pero procesos no están de verdad unidos

3. WMIC puede identificar procesos por su línea de comando exacta
   └─ Es cómo Windows sabe QUÉ proceso está usando QUÉ recurso

4. Solo matamos procesos de Chrome que contengan nuestra ruta específica
   └─ Tu Chrome personal NO tiene esa ruta en su línea de comando
   └─ Por lo tanto, NO MUERE
