## 🗺️ El Mapeo (Resumen)

```
READY
 ↓ (run invoked)
SESSION_SEED (session_bridge.py)
 ↓ (cookies + orderFormId)
ATC (checkout_orchestrator)
 ↓ (SKU en items)
PRICING_WAIT (orderform_watcher.wait_ready())
 ↓ (is_orderform_ready == True)
PRICING_FROZEN 🔴 (orderform_watcher.wait_frozen())
 ↓ (snapshot A == B en 400ms)
 ⚠️ CONTRATO: Nunca más se valida pricing
 ↓
PAYMENT_BANK_SELECTED (payment_engine.set_bank_payment())
 ↓ (backend call, sin UI)
BANK_MODAL_OPEN (bank_payment_flow.select_bank_and_finalize())
 ↓ (click banco + finalizar)
AWAITING_HUMAN_CONFIRMATION 🟢 (TERMINAL)
 ↓
El usuario confirma en su banco
El bot NO toca nada más
```

---

## 🔑 Lo Crítico (Que Gana o Pierde)

### 1️⃣ PRICING_FROZEN

**Por qué es el punto de no retorno:**
- Snapshot A == Snapshot B en 400ms
- Después: NUNCA más se valida pricing
- Garantiza que VTEX no recalcula

**Si se salta:** $0, antifraude, falla.
**Si se respeta:** Estable siempre.

### 2️⃣ Banco Principal

**Por qué es decisión de READY:**
- No runtime decision
- Backend inyectado en PAYMENT_BANK_SELECTED
- Sin UI de selección (ya está decidido)

**Si se decide en runtime:** Timing issues, cambios mid-drop.
**Si está predefinido:** Determinista, rápido.

### 3️⃣ Playwright Mínimo

**Por qué solo SESSION_SEED + BANK_MODAL:**
- UI es lenta
- Backend es determinista
- Modal es necesario pero rápido

**Si es todo UI:** Bugs, timing, antifraude.
**Si es backend + UI mínima:** Velocidad + estabilidad.

import asyncio
from engines.state_machine_orchestrator import StateMachineOrchestrator
from vtex.tls_client_vtex import TlsVTEXClient
from playwright.async_api import async_playwright

async def ganar_checkout():
    orchestrator = StateMachineOrchestrator("https://www.nike.cl")
    vtex = TlsVTEXClient("https://www.nike.cl", cookies={...})
    
    async with async_playwright() as p:
        context = await p.chromium.launch_persistent_context(...)
        page = context.pages[0]
        
        async def session_fn():
            # Crear sesión
            return True
        
        async def atc_fn(sku, seller):
            return vtex.add_to_cart(sku, seller) is not None
        
        # Ejecutar
        result = await orchestrator.run_full_flow(
            account_name="cuenta1",
            sku="12345",
            seller="321",
            bank_name="Banco Santander",
            session_fn=session_fn,
            atc_fn=atc_fn,
            get_orderform_fn=lambda: vtex.get_order_form(),
            vtex_client=vtex,
            page=page
        )
        
        print(f"Estado final: {result['state'].name}")
        print(f"Éxito: {result['success']}")
        # Output:
        # Estado final: AWAITING_HUMAN_CONFIRMATION
        # Éxito: True
        
        await context.close()

asyncio.run(ganar_checkout())
