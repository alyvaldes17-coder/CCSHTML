⚙️ ARQUITECTURA

  Hybrid Handover = Backend (Python) + Frontend (Chrome)

    Python (El Cerebro):
    ├─ Conecta via CDP
    ├─ Roba cookies de Chrome
    ├─ Hace GET al magic link VTEX
    └─ Agrega al carrito en servidor (sin cargar UI)
       ↓ RESULTADO: 0.2s

    Chrome (La Cara):
    ├─ Ya tiene el item en carrito (gracias a Python)
    ├─ Navega directo a /checkout/#/payment
    ├─ Se salta la animación de "Agregando..."
    └─ Usuario ve tarjeta de crédito lista
       ↓ RESULTADO: 0.5s

    TOTAL: ~0.7s (Python 0.2s + Chrome 0.5s)
