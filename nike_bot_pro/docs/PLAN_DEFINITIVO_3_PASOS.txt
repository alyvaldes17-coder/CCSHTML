## 🔧 SOLUCIÓN Si falla el Test

### Caso 1: "No hay cookies"
**Causa más probable:** User no cerró Chrome correctamente

**Solución:**
1. Ejecuta nuevamente
2. Asegúrate de cerrar con la **X** (no solo la pestaña)
3. Espera 2 segundos después de cerrar

### Caso 2: "Permiso denegado" / "Cannot write to directory"
**Causa:** Windows bloqueó permisos en `auth/`

**Solución:**
1. Abre PowerShell **COMO ADMINISTRADOR**
2. Ejecuta:
```powershell
cd "c:\Users\beriann\Documents\Repos\nike_bot_pro"
python test_login_persistence.py
```

### Caso 3: Chrome no abre
**Causa:** Chrome no está en rutas estándar

**Solución:**
1. Instala Chrome desde https://www.google.com/chrome
2. O verifica que está en `C:\Program Files\Google\Chrome\Application\chrome.exe`
