│ 🎯 EL FLUJO                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

ANTES DEL DROP:
  1. python main.py
  2. Click [🔐 LOGIN] por cuenta
  3. Usuario loguea → Cookies guardadas
  4. Estado: ✅ LOGUEADO

EN EL DROP:
  1. Click [▶ PLAY]
  2. FASE A: Backend detecta precio (rápido)
  3. FASE B: Chrome abre automáticamente
  4. Usuario ve carrito + paga
  5. ✅ ORDER COMPLETADA

     pip install playwright requests customtkinter
     playwright install

     python main.py
