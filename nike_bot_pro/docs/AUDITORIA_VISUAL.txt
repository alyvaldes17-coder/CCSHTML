### 3️⃣ **E4: Circuit breaker** (30 minutos)
```python
# ❌ ANTES: Sin circuit break, espera siempre
while time.time() - start < timeout:
    of = self.fetch()  # Si VTEX devuelve 500, sigue esperando
    if self.is_ready(of):
        return of
    time.sleep(0.25)

# ✅ DESPUÉS: Fail-fast en 5xx, abort en 3+ errores
while time.time() - start < timeout:
    r = self.session.get("/api/checkout/pub/orderForm")
    
    if r.status_code >= 500:
        raise RuntimeError(f"VTEX circuit open: {r.status_code}")  # ← FAIL FAST
    
    consecutive_errors += 1
    if consecutive_errors >= 3:
        raise RuntimeError("Too many errors")  # ← ABORT
```

**Archivos:** `engines/orderform_watcher.py`  
**Impacto:** -70% MTTR en outages, +100% fail-fast
