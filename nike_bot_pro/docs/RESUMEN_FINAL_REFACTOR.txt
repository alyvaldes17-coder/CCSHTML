⚠️ LIMITACIONES HONESTAS

1. Nike puede cambiar selectores
   → Solución: Ejecuta test_selectores_nike.py cada semana

2. Fintoc puede no abrirse
   → Razón: Cookie expirada o sesión inválida
   → Solución: Presiona LOGIN de nuevo

3. Usuario puede no autorizar
   → Razón: Fondos insuficientes, límite excedido
   → Bot no puede hacer nada (es humano)

4. Drops rápidos pueden fallar
   → Razón: PRICING_WAIT timeout (30s default)
   → Solución: Aumentar timeout si necesitas
