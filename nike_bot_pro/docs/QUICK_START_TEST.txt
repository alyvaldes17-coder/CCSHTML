                       SI FALLA - SOLUCIONA ESTO:
==============================================================================

PROBLEMA 1: "NO HAY COOKIES"

Causas posibles:
  • No cerraste Chrome correctamente (solo cerraste la pestaña)
  • Permisos de Windows bloqueados
  • Chrome no está en la ruta esperada

Soluciones:
  • Intenta nuevamente
  • Asegúrate de usar la X para cerrar Chrome
  • Ejecuta como Administrador:
    - PowerShell > Click derecho > "Ejecutar como administrador"
    - Corre: python test_login_persistence.py


PROBLEMA 2: "Chrome no abre"

Causa: Chrome no instalado en rutas estándar

Solución:
  • Instala Chrome desde google.com/chrome
  • O verifica que está en: C:\Program Files\Google\Chrome\Application\chrome.exe


PROBLEMA 3: "Error de sintaxis / ImportError"

Causa: Archivo dañado o Python antiguo

Solución:
  • Verifica: python --version (debe ser 3.8+)
  • Reinstala dependencias: pip install -r requirements.txt
